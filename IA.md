# Uso de IA en proyecto Front End
Se utilizó IA para hacer la estructura básica de algunos html y el css inicial de la mayoría, para luego ir detallando y mejorando de forma propia (ambos, html y css). Como prompt se le pedía las instrucciones básicas del diseño y respondía con la estructura base del html y css, esto no se hizo con todos los archivos, pero si con los que requerían más elementos para así agilizar el trabajo. A veces el código con el que respondía traía pocos errores y otras veces bastantes, por lo que obviamente de forma propia debía ir arreglando cada error, hasta que el diseño quedara como quería y como se pedía para la evaluación.

También se utilizó la IA para entender bien la función de cada parte del código y consultar en específico cuando se necesitaba arreglar algún detalle. Como prompt se le enviaba el código que llevaba hasta el momento y pedía explicación línea por línea para ir estudiandolo. Cuando se requería agregar o mejorar algún detalle y no sabía cómo, se le preguntaba de que forma se podía realizar. A esto último no siempre respondía inmediatamente con la solución correcta y a veces se debía preguntar desde otro enfoque para poder resolver la problemática (Por ej: si preguntaba como arreglar un error en especifico y lo que respondía no servía, mejor preguntaba qué comando era el mejor para hacer el diseño que necesitaba y como este se utilizaba).
